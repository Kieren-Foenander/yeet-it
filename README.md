# yeet it

A daily word game: make a shorter word, yeet the unused letters forever, and build the longest chain you can.

Everyone starts with the same nine-letter word. Rearrange freely, drop at least one letter each turn, and finish at three letters. Each new word scores one point, for a maximum of six.

Built with Effect v4 and Foldkit, hosted on Cloudflare Workers, and deployed with Alchemy.

Implementation is underway. The original playable mechanics experiment is in `prototype/`; the agreed implementation brief is in [docs/BUILD.md](docs/BUILD.md).
