# Data

| Path | What | Licence |
| --- | --- | --- |
| `enable/enable1.txt` | Accepted-word dictionary (ENABLE, pinned snapshot) | Public domain; see `enable/NOTICE.md` |
| `wordfreq/enable-zipf-en.tsv` | Familiarity scores for the generator | CC BY-SA 4.0; see `wordfreq/NOTICE.md` |
| `schedule.json` | Published, immutable date → puzzle assignments | Generated by `pnpm puzzles:generate` |

`schedule.json` is append-only. Each entry records the generator, dictionary, and
frequency versions it was produced with. `pnpm puzzles:verify --published <old>`
fails if any published entry changes.
